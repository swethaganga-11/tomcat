# Tomcat and Apache HTTP Server – Fresher Interview Questions

## 1. What is Apache Tomcat?

Apache Tomcat is an open-source web application server used to run Java web applications. It supports technologies such as Java Servlets and JavaServer Pages (JSP).

**Example:** We can deploy a Java web application in Tomcat using a WAR file.

## 2. What is Apache HTTP Server?

Apache HTTP Server, also called `httpd`, is a web server. It receives HTTP/HTTPS requests from users and serves web pages or forwards requests to an application server.

**Example:** When we enter a website URL in a browser, Apache HTTP Server can receive the request and return the website content.

## 3. What is the difference between Apache HTTP Server and Tomcat?

| Apache HTTP Server | Tomcat |
|---|---|
| It is a web server. | It is a Java web application server. |
| It serves static content such as HTML, CSS, and images. | It runs Java web applications. |
| The default HTTP port is 80. | The default HTTP port is 8080. |
| The service is commonly called `httpd` on Linux. | The service is commonly called `tomcat` or `tomcat10`, depending on installation. |

## 4. What is a web server?

A web server receives requests from clients and returns web content through HTTP or HTTPS.

**Examples:** Apache HTTP Server and Nginx.

## 5. What is an application server?

An application server provides an environment to run application code and process application requests.

**Example:** Apache Tomcat runs Java web applications.

## 6. What is a WAR file?

WAR stands for **Web Application Archive**. It contains the files required to deploy a Java web application.

**Example:** `myapp.war`

In Tomcat, we can commonly deploy the WAR file into the `webapps` directory.

## 7. What is a JAR file?

JAR stands for **Java Archive**. It packages Java classes and other resources into a single file.

**Example:** `myapp.jar`

## 8. What is an EAR file?

EAR stands for **Enterprise Archive**. It packages enterprise Java application components for compatible enterprise application servers.

Tomcat is not a full Java EE/Jakarta EE application server and does not natively deploy EAR files like WildFly or traditional JBoss EAP.

## 9. What are the important directories in Tomcat?

| Directory | Purpose |
|---|---|
| `bin` | Contains startup and shutdown scripts. |
| `conf` | Contains configuration files. |
| `lib` | Contains libraries used by Tomcat. |
| `logs` | Stores log files. |
| `webapps` | Contains deployed web applications. |
| `work` | Stores generated working files. |
| `temp` | Stores temporary files. |

**Interview answer:** The `bin` directory contains scripts, `conf` contains configuration files, `logs` contains logs, and `webapps` contains deployed applications.

## 10. What is the Tomcat configuration file?

The main Tomcat configuration file is:

`conf/server.xml`

It is used to configure connectors, ports, virtual hosts, and other server settings.

## 11. What is the default port of Tomcat?

The default HTTP connector port is usually **8080**.

Example URL:

`http://localhost:8080`

The port may be changed in the `server.xml` configuration file.

## 12. What are the default ports of Apache HTTP Server?

- HTTP: Port 80
- HTTPS: Port 443

These are the standard ports, but the server can be configured to use other ports.

## 13. How do you install Apache HTTP Server on Amazon Linux?

First, connect to your EC2 instance.

Update the packages:

```bash
sudo dnf update -y
```

On Amazon Linux 2, use:

```bash
sudo yum update -y
```

Install Apache HTTP Server:

```bash
sudo dnf install httpd -y
```

Start the service:

```bash
sudo systemctl start httpd
```

Enable it at boot:

```bash
sudo systemctl enable httpd
```

Check its status:

```bash
sudo systemctl status httpd
```

**Note:** The package manager and package availability depend on your Linux distribution.

## 14. What are the important Apache HTTP Server paths?

| Path | Purpose |
|---|---|
| `/etc/httpd/conf/httpd.conf` | Main configuration file on many RHEL-based systems. |
| `/etc/httpd/conf.d/` | Additional configuration files. |
| `/var/www/html/` | Common default website document root. |
| `/var/log/httpd/` | Common directory for Apache log files. |

Paths may differ depending on the Linux distribution and installation method.

## 15. How do you start, stop, and restart Apache HTTP Server?

Start:

```bash
sudo systemctl start httpd
```

Stop:

```bash
sudo systemctl stop httpd
```

Restart:

```bash
sudo systemctl restart httpd
```

Check status:

```bash
sudo systemctl status httpd
```

Enable at boot:

```bash
sudo systemctl enable httpd
```

## 16. How do you check Apache configuration errors?

Run:

```bash
sudo httpd -t
```

If the configuration is valid, the output is usually:

```text
Syntax OK
```

## 17. How do you check Apache HTTP Server logs?

Check the error log:

```bash
sudo tail -f /var/log/httpd/error_log
```

Check the access log:

```bash
sudo tail -f /var/log/httpd/access_log
```

- **Access log:** Records incoming requests.
- **Error log:** Records errors and diagnostic messages.

## 18. How do you check whether a port is listening?

Run:

```bash
sudo ss -tulnp
```

To check port 80:

```bash
sudo ss -tulnp | grep ':80'
```

To check port 8080:

```bash
sudo ss -tulnp | grep ':8080'
```

## 19. How do you install Java?

On Amazon Linux, you can search for available Java packages:

```bash
sudo yum search java-openjdk
```

On systems that use DNF:

```bash
sudo dnf search java-openjdk
```

Install a suitable Java version supported by your Tomcat release. For example, on a compatible system:

```bash
sudo dnf install java-21-openjdk-devel -y
```

Verify the installation:

```bash
java -version
```

**Important:** Check the Java requirements for your specific Tomcat version before installing Java.

## 20. How do you install Tomcat?

A common manual installation process is:

1. Install a compatible Java version.
2. Download a supported Tomcat release from the official website.
3. Extract the downloaded archive.
4. Configure permissions and environment settings if required.
5. Start Tomcat.
6. Check the logs and confirm that the service is running.

Official download website:

https://tomcat.apache.org/

The exact commands depend on the Tomcat version and Linux distribution.

## 21. How do you start and stop Tomcat?

If Tomcat was installed manually, go to its installation directory.

Start Tomcat:

```bash
./bin/startup.sh
```

Stop Tomcat:

```bash
./bin/shutdown.sh
```

Check the logs:

```bash
tail -f logs/catalina.out
```

**Note:** Some installations use systemd services instead of these scripts.

## 22. How do you check whether Tomcat is running?

Check the process:

```bash
ps -ef | grep '[o]rg.apache.catalina.startup.Bootstrap'
```

Check the port:

```bash
sudo ss -tulnp | grep ':8080'
```

Test the local endpoint:

```bash
curl -I http://localhost:8080
```

These commands help you verify the process, listening port, and HTTP response.

## 23. How do you deploy a WAR file in Tomcat?

Suppose your application file is `myapp.war`.

Copy the WAR file into the Tomcat `webapps` directory.

For example:

```bash
cp myapp.war /path/to/tomcat/webapps/
```

Tomcat can automatically deploy the application if automatic deployment is enabled.

You can then test:

```text
http://SERVER_IP:8080/myapp/
```

Replace `SERVER_IP` with the server's reachable IP address or hostname.

## 24. How do you change the Tomcat port?

Open the configuration file:

```bash
vi /path/to/tomcat/conf/server.xml
```

Find the HTTP connector configuration. It commonly contains a port setting similar to:

```xml
<Connector port="8080" protocol="HTTP/1.1"
           connectionTimeout="20000"
           redirectPort="8443" />
```

Change `8080` to an available port, save the file, and restart Tomcat.

**Important:** Do not change unrelated port settings accidentally.

## 25. What is a reverse proxy?

A reverse proxy receives client requests and forwards them to backend servers.

**Example:**

```text
Client
  |
  v
Apache HTTP Server :80
  |
  v
Tomcat :8080
  |
  v
Java Web Application
```

Apache HTTP Server can be configured as a reverse proxy in front of Tomcat.

## 26. What is the difference between HTTP and HTTPS?

- **HTTP:** Transfers web data without transport encryption by itself.
- **HTTPS:** Uses TLS to encrypt communication between the client and server.

HTTPS is normally accessed through port 443.

## 27. What is a log file?

A log file records events, requests, warnings, and errors generated by a server or application.

**Example:** If Tomcat fails to start, its logs may show a port conflict, Java problem, or configuration error.

## 28. What is the difference between an access log and an error log?

| Access Log | Error Log |
|---|---|
| Records client requests. | Records errors and diagnostic information. |
| Helps investigate HTTP requests and responses. | Helps investigate configuration and runtime problems. |
| Useful for request analysis. | Useful for troubleshooting failures. |

## 29. Scenario: Tomcat is not starting. What will you do?

**Fresher answer:**

First, I will check the Tomcat service or process status. Then I will check the Tomcat logs for errors. I will verify the Java version, configuration files, permissions, and whether another process is using the required port. After identifying and fixing the issue, I will start Tomcat and test the application.

Useful commands:

```bash
ps -ef | grep '[o]rg.apache.catalina.startup.Bootstrap'
```

```bash
sudo ss -tulnp | grep ':8080'
```

```bash
tail -n 100 /path/to/tomcat/logs/catalina.out
```

## 30. Scenario: The website is not opening. What will you check?

**Fresher answer:**

First, I will check whether the web server is running. Then I will verify the server IP address, port, firewall rules, security group, and application logs. I will test the service locally and then test it from the client side.

Useful commands:

```bash
sudo systemctl status httpd
```

```bash
curl -I http://localhost
```

```bash
sudo ss -tulnp
```

## 31. Scenario: Apache returns a 403 Forbidden error. What will you do?

**Fresher answer:**

A 403 error means the server understood the request but is refusing access. I will check file and directory permissions, Apache access rules, the document root, and security policies such as SELinux where applicable. I will review the error log before changing any permissions.

Command:

```bash
sudo tail -n 100 /var/log/httpd/error_log
```

## 32. Scenario: Apache returns a 503 Service Unavailable error when forwarding to Tomcat. What will you do?

**Fresher answer:**

I will check whether Tomcat is running and listening on the configured backend port. Then I will verify Apache's reverse proxy configuration and review both Apache and Tomcat logs. I will test the backend directly from the server.

Commands:

```bash
sudo systemctl status httpd
```

```bash
curl -I http://localhost:8080
```

```bash
sudo tail -n 100 /var/log/httpd/error_log
```

A 503 error can have several causes, so I will use the logs to identify the actual problem.

## 33. Scenario: The application works locally but cannot be accessed from outside an EC2 instance. What will you check?

**Fresher answer:**

I will check whether the application is listening on the correct interface and port. Then I will check the EC2 security group, network ACLs, route table, operating system firewall, and the URL being used. I will also review server logs.

**Security note:** Open only the ports that are required. Do not expose Tomcat's management interfaces publicly.

## 34. What is the difference between `start`, `stop`, and `restart`?

- `start`: Starts the service.
- `stop`: Stops the service.
- `restart`: Stops and starts the service again.

Example:

```bash
sudo systemctl start httpd
sudo systemctl stop httpd
sudo systemctl restart httpd
```

## 35. What is Maven?

Maven is a build automation and dependency management tool commonly used for Java projects.

It can compile code, run tests, package applications, and download project dependencies.

Example:

```bash
mvn clean package
```

This command cleans previous build output and builds the project through its configured lifecycle, including applicable tests and packaging.

## 36. How are Maven and Tomcat connected?

Maven can build a Java web application and package it as a WAR file. Tomcat can then deploy and run that WAR file.

**Workflow:**

```text
Java Source Code
       |
       v
     Maven
       |
       v
    WAR File
       |
       v
     Tomcat
       |
       v
   Web Application
```

## 37. What is the difference between `catalina.out` and Apache error logs?

- `catalina.out`: Commonly captures Tomcat console output on Unix-like systems when the installation is configured to redirect output there.
- Apache `error_log`: Records Apache HTTP Server errors and diagnostic messages.

The exact log locations depend on how each server is installed and configured.

## 38. How do you troubleshoot a server issue?

**Fresher answer:**

I will follow these steps:

1. Check the service status.
2. Check the process and listening port.
3. Review the application and server logs.
4. Check the configuration files.
5. Verify network connectivity and firewall rules.
6. Identify the root cause.
7. Apply the appropriate fix.
8. Restart the service if required and test again.

## 39. What is the difference between static and dynamic content?

- **Static content:** Files served as they are stored, such as HTML, CSS, JavaScript, and images.
- **Dynamic content:** Content generated or processed based on application logic or data.

Apache HTTP Server commonly serves static content. Tomcat runs Java web applications that can generate dynamic content.

**Sample answer:**
